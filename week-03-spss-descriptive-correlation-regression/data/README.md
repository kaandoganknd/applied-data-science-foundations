# Source data

The source datasets are excluded from this public repository. To run the analysis, place the following files in a local folder and update the absolute input paths in the syntax files:

- `Salary_data.xlsx` (worksheet: `in`)
- `House_prices.csv`
- `weather.xlsx` (worksheet: `weather`)

The supplied SPSS Viewer file is included only as analysis evidence. It does not contain the raw datasets.
