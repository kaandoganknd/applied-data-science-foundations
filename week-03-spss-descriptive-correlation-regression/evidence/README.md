# SPSS Viewer evidence

`weather_analysis_output.spv` is a saved IBM SPSS Statistics Viewer file for the weather exercise. It contains descriptive outputs, distribution checks, boxplots, and correlation tables for the weather variables.

The Week 3 weather syntax extends that work with a documented regression model. The `.spv` file is provided for users who have IBM SPSS Statistics installed; the source `weather.xlsx` file is not included.
