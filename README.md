# Applied Data Science Foundations

A collection of reproducible exercises and projects developed during postgraduate study in data science.

Each folder contains the analysis code, a concise summary of the findings, and clear instructions for reproducing the work. Source datasets are excluded when redistribution rights are unclear.

## Projects

- [SPSS Data Quality and Descriptive Statistics](week-02-spss-data-quality-and-descriptive-statistics/) — data-quality checks, cleaning decisions, descriptive analysis, and SPSS syntax for Iris and daily weather data.

## Tools

IBM SPSS Statistics, Python, SQL, and data-visualisation tools will be added as the collection develops.
